## Authority and scope

This repository is an official public distribution of Louisiana AI Signals.

It is **not** an independent system of record. The Public Ledger at LouisianaAIHub.com remains the authoritative current source. If this repository differs from the current Ledger, the current Ledger controls.

Louisiana AI Signals records use stable `LAIS-####` identifiers. The same LAIS identifier is retained across LouisianaAIHub.com and approved external distributions.

Identifiers are stable and may be non-contiguous. The current snapshot contains 328 occupied historical records within the range `LAIS-0001` through `LAIS-0350`; record count must not be inferred from the highest identifier.

This repository is limited to the **Louisiana AI Signals / Public Ledger** dataset.

It does not distribute:

* the Louisiana AI Hub Source Register as a dataset;
* preserved source PDFs or source-reference PDFs;
* project-profile datasets;
* parish or Parish Intelligence datasets;
* Power & Grid datasets;
* Water & Utility datasets;
* commercial or Project Intelligence data;
* internal research or unpublished intelligence.

## Public distribution files

The official snapshot package includes:

* `louisiana-ai-signals-public-ledger.csv`
* `louisiana-ai-signals-public-ledger.json`
* `louisiana-ai-signals-public-ledger-manifest.json`
* `SHA256SUMS.txt`

The CSV and JSON contain the governed Public Ledger records and approved provenance metadata.

The manifest identifies the publisher, dataset version, snapshot date, canonical authority, record range, distribution files, and integrity information.

`SHA256SUMS.txt` provides SHA-256 hashes for the canonical CSV, JSON and manifest distribution files. The manifest supplies release metadata and repeats the CSV and JSON file hashes.
